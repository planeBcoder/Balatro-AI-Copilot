# Balatro AI Copilot · 小丑牌 AI 副驾驶

读取真实牌局，本地验算 + AI 比较，在游戏里直接显示出牌和商店建议。
无需截图；能核实当前手牌直接过关时，优先收官；不强凑低概率同花顺。

Windows 公测版 1.6.0-beta.1。非官方项目，需要自行购买游戏和配置 API Key。

## 下载和使用

1. 从 [Releases](https://github.com/planeBcoder/Balatro-AI-Copilot/releases) 下载
   `Balatro-AI-Copilot-1.6.0-beta.1-Setup.exe`，不是源码 ZIP。
2. 退出游戏，运行安装程序。完成后确认自动检测的游戏目录，点击“安装并适配 / 修复”。
   Steam 多游戏库会自动检测，也可手动选择包含 Balatro.exe 的目录。
3. 打开副驾驶，在设置填写你自己的 DeepSeek API Key，然后启动游戏。
4. 选牌或商店中按 F9 获取建议；F10 显示 / 隐藏面板。
   设置入口在桌面浮窗或右下角托盘；游戏内面板连接后桌面浮窗会隐藏。

不需要安装 Python。适配组件离线提供；AI 分析需要网络，费用由你自己的账户承担。
部分确定性收官可以完全本地判断。首次安装或更新组件后需重启游戏，不强制结束当前牌局。

## 支持范围

| 项目 | 当前范围 |
|---|---|

额外玩法模组可能使计分无法认证；能显示不等于策略支持该模组。

## 半自动和自动

普通 F9 建议不替你点牌或购买物品。商店 F9 与自动策略共用本地价格、槽位、
利息和构筑核算，再让 AI 比较，不是只按大牌型排序。

试自动：设置勾选“允许实验自动打牌”，重启游戏后按 F11 启停当前盲注。
F12 紧急停止，游戏内 Escape 也可取消。遇到商店、结算、未知效果或状态变化会停止。
完整自动流程从开始菜单打开 Experimental isolated trainer，使用单独档案。
一次通关验证不代表稳定通关率，不保证所有牌组或随机种子能胜利。

## 数值和隐私

确定性得分与补牌事件概率来自本地核算，AI 不允许编造这些数字。
“模拟次数”只控制复杂补牌事件的抽样精度 / 耗时，不是 AI 思考次数。
未知动态效果会降级说明；未算完整多回合策略树时，不声称有精确整局胜率。

按 F9 / 开启自动模式会向 DeepSeek 发送游戏状态，可能产生 API 费用。
密钥仅由 Windows 加密保存在本机，不发给作者；没有遥测或内置共享密钥。
导出器能读取牌池乃至实际顺序，可能超出普通玩家可见信息，不适合赛事和公平竞争。
详见 [隐私说明](PRIVACY.md)。

## 修复和卸载

- 设置 → 检测游戏 / 修复安装，或开始菜单 Game setup and repair。
- 先退出游戏再修改组件；不会强制关闭游戏。
- Windows 设置 → 应用 → Balatro AI Copilot → 卸载。
- 卸载恢复本项目替换前的文件，移除新增自有模组。
  用户后续修改的文件会保留并阻止静默卸载，需检查后重试。
- Lovely / Steamodded 是共享加载器，保留以免破坏其他模组。
  设置、密钥和恢复备份默认保留，清理办法见 PRIVACY.md。
- 安装包未签名，可能触发 Windows 信誉提示。请核验发布源和 SHA256SUMS.txt，
  不关闭系统保护强行安装。[安全边界](SECURITY.md)。
